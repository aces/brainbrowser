🧠 BrainBrowser - Simple Demo

Advanced 3D Surface Visualization with Clipping, Electrodes & Time Series

⚠️ Important: Must Run on HTTP Server

This demo requires a local web server. To run:

cd brainbrowser then python3 -m http.server 8000

Then open: http://localhost:8000/examples/simple-demo.html
